# Phishing Email Detection Model

## 📌 Project Overview
This project is a Machine Learning model that detects whether an email is **Phishing or Safe** based on its text content using Natural Language Processing (NLP).

## 🧠 Technologies Used
- Python
- Pandas
- Scikit-learn
- Numpy
- Matplotlib
- Seaborn

## ⚙️ How It Works
- Email text is converted into numerical features using TF-IDF
- Logistic Regression model is trained on labeled dataset
- Model predicts whether an email is phishing or safe

## 📊 Output
- Accuracy score
- Confusion matrix
- Classification report
- Sample predictions
